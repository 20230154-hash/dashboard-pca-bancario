05 / METODOLOGÍA

Cómo se obtuvo este resultado

1. Preparación

Del archivo bank-additional-full.csv se tomaron las 10 variables predictoras numéricas. Se excluyeron las variables de texto y se separó y como objetivo.

2. Estandarización y PCA

Se aplicó StandardScaler y luego PCA. Los primeros seis componentes conservan el 91,54 % de la varianza de las variables numéricas estandarizadas.

3. Exploración

La web muestra los componentes exportados. PCA no usa y para calcularlos; aquí y permite comparar las clases. No se ha entrenado un modelo predictivo ni medido su precisión.

El porcentaje de varianza no es un porcentaje de exactitud de clasificación. Para evaluar un futuro modelo, el escalado y PCA deben ajustarse solo sobre los datos de entrenamiento.
